# C-VEPRES 0.1.0-beta.1

Windows 64-bit รองรับ VST3 และ CLAP

M/S Compressor แบบมีคาแรกเตอร์ชัดเจน: แยก 3 ย่านความถี่ทั้งฝั่ง mid และ side
มี soft clipper และ true-peak limiter ในตัว เสียงหลักถูกจูนมาแล้วมีปุ่มให้ปรับจากจุดนั้นแค่ไม่เยอะมาก

**BETA** ยังไม่ต้องแชร์ต่อนะ ถามก่อน เพราะยังมี bug อยู่บ้าง

## ติดตั้ง

| ฟอร์แมต | ไฟล์              | คัดลอกไปที่                             |
| ------- | ----------------- | ------------------------------------- |
| VST3    | `C-VEPRES.vst3`   | `C:\Program Files\Common Files\VST3\` |
| CLAP    | `C-VEPRES.clap`   | `C:\Program Files\Common Files\CLAP\` |

แล้วสั่ง rescan ปลั๊กอินใน DAW

## วิธีใช้

ใช้กับแทร็กหรือบัสที่เป็น stereo เท่านั้น (เพราะทำงานแบบ mid/side)
ถ้าทุก knob อยู่ที่ค่าเริ่มต้น จะได้เสียงที่ปรับจูนไว้ ปุ่มต่าง ๆ ใช้ขยับจากจุดนั้น:

| ปุ่ม           | หน้าที่                                                              |
| ------------- | ------------------------------------------------------------------- |
| 01 INPUT      | เกนขาเข้า (±12 dB) ยิ่งดันมาก คอมเพรสเซอร์กับ clipper ยิ่งทำงานหนัก      |
| 02 THRESHOLD  | บวกเข้ากับ threshold ของทุกย่าน (±12 dB) หมุนขึ้น = คอมเพรสน้อยลง      |
| 03 WIDTH      | ระดับเสียงฝั่ง side หลังคอมเพรส (±6 dB)                                |
| 04 OUTPUT     | เกนขาออก อยู่ท้ายสุดของทุกอย่าง (±12 dB)                                |
| 05 MIX        | dry/wet สัญญาณ dry ถูกชดเชยดีเลย์ให้ตรงกันแล้ว                            |
| 06 LIMITER    | true-peak limiter ท้ายเชน ประมาณ -1 dBTP เปิดไว้เป็นค่าเริ่มต้น             |
| 07 CLIP       | soft clipper ก่อนเข้าแต่ละย่าน มี `OFF`, `ON` (ค่าเริ่มต้น) และ `2X`       |

- **โหมด CLIP:** `ON` จะแตะแค่พีคที่ใกล้ 0 dBFS ส่วน `2X` คือ clipper ตัวเดิม
  แต่รันที่ sample rate สองเท่า peak ที่ดังจัดจะได้ไม่สะท้อนกลับมาเป็นเสียงแหลมบาดหู
  แลกกับ CPU เพิ่มอีกนิด ส่วน `OFF` คือข้าม clipper ไปเลย
- **ปุ่มหมุน:** ลากขึ้น/ลง กด Shift ค้างไว้เพื่อปรับละเอียด ดับเบิลคลิกเพื่อรีเซ็ต
- **คำอธิบาย:** เอาเมาส์ไปชี้ที่ปุ่มไหน จะมีคำอธิบายขึ้นที่ด้านล่างของหน้าต่าง
- **หน้าต่าง:** ปรับขนาดได้ ลากที่มุมหน้าต่าง
- **Latency:** ประมาณ 11 ms ที่ 48 kHz DAW จะชดเชยให้อัตโนมัติ

## ข้อจำกัดที่รู้อยู่

- เช็กที่ 48 kHz ส่วน 44.1, 88.2 และ 96 kHz เช็กแล้วเสียงเหมือนกัน
- เบสที่ดังมาก ๆ ในฝั่ง side อาจออกมาดังกว่าที่ตั้งใจประมาณ 0.4 dB
- มิเตอร์แสดง gain reduction ตั้งแต่ 0 ถึง -12 dB ถ้าลดลึกกว่านั้นก็ยังทำงานปกติ
  แค่มิเตอร์จะค้างอยู่ที่สุดสเกล

## ฟีดแบ็ก

อยากรู้เรื่องพวกนี้:

- เสียงเป็นยังไงกับงานของคุณ เทียบกับปลั๊กอินที่ใช้ประจำ
- CPU ที่ใช้ ตอนตั้ง `CLIP` เป็น `ON` และ `2X`
- แครช เสียงคลิก หรือเสียงกระตุก
- DAW ที่ใช้ + เวอร์ชัน, sample rate และ buffer size
